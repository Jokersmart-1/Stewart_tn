📌 Tóm tắt luồng thực thi:

  1. MATLAB tính toán động học nghịch sóng $\rightarrow$ xuất file trajectory.csv (chuỗi xung & DIR lý thuyết).
  2. PC Web Server nạp dữ liệu $\rightarrow$ truyền gói lệnh qua USB/Serial xuống MCU (STM32).
  3. MCU phát xung tại các chân GPIO $\rightarrow$ Logic Analyzer đo và xuất file measured.csv qua phần mềm Logic SW.
  4. MATLAB đọc measured.csv $\rightarrow$ tính ngược hành trình 6 chân $\rightarrow$ xuất file motion.csv.
  5. RecurDyn nạp file motion.csv để mô phỏng chuyển động sóng thực tế trên mô hình 3D Stewart Platform.
